# Futuriza — Protótipo V1

Protótipo navegável e simulado para apresentação da startup Futuriza.

## Identidade visual
- Azul principal: `#0254E6`
- Azul secundário: `#2F78F0`
- Amarelo de destaque: `#FBBF05`
- Logo oficial incluída em `public/futuriza-logo.png`

## Fluxos principais
- Início → Teste → Resultado
- Resultado → “Não me identifiquei” → Lumi
- Carreiras → detalhe da profissão → cursos
- Cursos → detalhes do curso
- Minha Jornada → “Fiz algo!” → conversa simulada com Lumi → nova meta

## Rodar localmente
```bash
npm install
npm run dev
```

O projeto foi pensado como protótipo de pitch: as interações são pré-configuradas e não dependem de backend ou API externa.
